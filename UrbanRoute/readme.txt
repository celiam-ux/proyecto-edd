UrbanRoute - Red de transporte

Descripcion:
UrbanRoute es una aplicacion de escritorio en Java (Swing) que carga desde archivos CSV
las estaciones y conexiones de una red de transporte, las representa en un grafo
ponderado implementado con estructuras de datos propias y permite editarlas,
visualizar la red, calcular la ruta mas rapida entre dos estaciones (Dijkstra),
detectar subredes desconectadas e identificar las estaciones hub.
